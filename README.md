# Tessy Tesseract Kids Lab

Joyful, single-file museum lab to explore **0D → 4D** with Tessy the tesseract.

**Live demo:** open [`kids.html`](./kids.html) (double-click — no server needed).

## What it is

- Pure HTML + Canvas + React (bundled), **no external deps** at runtime
- **Dimension Machine:** Dotty → Liney → Squarey → Cubey → Tessy  
  Corners: **1 → 2 → 4 → 8 → 16**
- Ghost Friends slider (1–6 layers) shows 4D “shadows”
- Twist Fan (0–180°) rotates in the 4th dimension (W); the arrow flips after 90°
- Drag the canvas to spin, plus big buttons: Spin / Mirrors / Unfold / Reset
- 3 quests with star badges for kids

## How to use

1. Open `kids.html` (double-click or any static host)
2. Tap **Dotty → Tessy** and watch the corners double
3. Drag the cube, add ghost friends, twist the fan
4. Find Tessy’s little face in the inner cube!

## For teachers / museums / homeschool

- Tested around 390px and up — works on tablets and projectors
- No tracking, no accounts, fully offline-ready
- Kid-friendly colors, big rounded buttons, clear labels
