✦ Meet Tessy! The 4D Cube

Kids Museum Mode — Dimension Machine, Ghost Friends, Twist Fan, and 3 quests.

This repository holds the project. The full interactive single-file lab (~195 KB, pure HTML + Canvas + bundled React) is the version you provided as React Artifact.html.

To complete the setup:

  1. Rename your file to kids.html
  2. Upload / replace it in this repo (or open a PR)

Once uploaded, anyone can open kids.html offline — no build step, no server required.

See the README for details. MIT licensed — free for schools, museums, and homeschool.
